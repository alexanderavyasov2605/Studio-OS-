# Дизайн-система Studio OS

Единый слой представления для сайта, Mini App и админки. Токены находятся в app/globals.css, компоненты — в components/ui. Новых UI-библиотек нет: React, Tailwind и нативные HTML-элементы.

## Токены
- Акцент #7C3AED, hover #6D28D9; светлый фон #F8F9FC, белые поверхности, текст #20202C. Семантические цвета info/success/warning/danger имеют отдельные мягкие фоны и контрастный текст.
- Шрифтовой стек Inter → Segoe UI → system-ui. Удалённая загрузка шрифтов не требуется; системный шрифт — совместимая альтернатива.
- Базовый текст 16px / 1.6, подписи 14px, пояснения 12px; заголовки адаптируются через clamp. Веса 400/500/600/700.
- Шаги интервалов 4/8/12/16/20/24/32/40/48/64px. Радиусы контролов 10px, карточек 16px, диалогов 24px. Мягкая тень карточек и отдельная тень всплывающих поверхностей.
- Интерактивные элементы имеют видимый focus-visible; основная высота/область нажатия — не менее 44px.

## Компоненты
| Компонент | Основной контракт |
| --- | --- |
| Button | variant primary/secondary/ghost/danger, size sm/md, loading, native disabled и ref |
| Input / Select | обязательный label, автоматический id, hint/error, aria-describedby/invalid, нативные props |
| Checkbox | нативный checkbox с label, hint/error, checked/defaultChecked и disabled |
| Tabs | label и items с id/label/content; стрелки, Home/End, пропуск disabled, связанные ARIA tab/panel |
| Card / Badge | поверхность; семантический tone для меток |
| Dialog | triggerLabel/title/description/children; showModal, Escape, фокус внутри и возврат к trigger |
| Table | caption, columns, rows и rowKey; th scope, пустое сообщение, перенос текста и локальный overflow |
| EmptyState | title/description/action, компактный вариант |
| Alert | title/tone; ошибка role=alert, остальные сообщения role=status |
| Skeleton | доступное название загрузки, aria-busy; без тяжёлой анимации |

Импортировать из components/ui. Для ссылок использовать Next Link с классами button; не вкладывать ссылку в кнопку. Отдельный OrderStatusBadge использует lib/order-status.ts как визуальный словарь, без серверных переходов или прав доступа. Текст остаётся видимым при отключении цвета.

## Оболочки и адаптация
- Публичный сайт: общий header, активные ссылки, мобильное details-меню с Escape.
- Админка: sidebar и header; на узком экране — меню разделов. Рабочих административных функций и авторизации по-прежнему нет.
- Mini App: собственная компактная оболочка и нижние вкладки с safe-area; переключается только демонстрационное представление, без Telegram SDK и операций.
- Сетки 2/3/4 колонки переходят к одной или двум. minmax(0,1fr), перенос текста и ограниченные поверхности предотвращают переполнение страницы.
- Reduced motion отключает переходы и вращение индикатора загрузки.

## Витрина
/ui-kit доступен только при NODE_ENV=development. В production серверная страница вызывает notFound; флаг окружения для публичного включения не предусмотрен. Витрина показывает цвета, элементы и все состояния, но не содержит заказов или выдуманных продаж.

Проверка: pnpm dev, затем /ui-kit. pnpm test:routes --dev проверяет доступность витрины; pnpm test:routes после build проверяет 404 в production.

Серверная архитектура, Prisma, секреты и хранилище этим слоем не изменяются. См. [архитектуру](ARCHITECTURE.md) и [прогресс](PROGRESS.md).
